# 01 — NumPy warmup

Trước khi cài model, làm quen tay với NumPy — thứ mình dùng suốt các bài sau.

Mở `warmup.py`, làm lần lượt các TODO. Mỗi hàm có test tương ứng trong
`test_warmup.py`; làm xong chạy:

```bash
uv run pytest fundamentals/01_numpy_warmup -q
```

Mục tiêu: quen với vector hoá (viết không dùng vòng `for` khi có thể),
broadcasting, và các phép reduce (`sum`, `mean`, `argmax`).
