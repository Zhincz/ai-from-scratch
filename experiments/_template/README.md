# Template thí nghiệm

Copy cả thư mục này ra khi bắt đầu một thí nghiệm mới, đặt tên theo ngày:

```bash
cp -r experiments/_template experiments/2026-07-18_ten-thi-nghiem
```

Mỗi thí nghiệm tự chứa: ghi lại **ý tưởng**, **kết quả**, **rút ra được gì** vào
README này để sau nhìn lại còn nhớ. `run.py` là chỗ code chính.
